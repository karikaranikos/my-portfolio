name: Portfolio copy and metric blocks
description: Editorial and layout preferences for work-detail statistics.
---

For portfolio work pages, do not remove or rewrite paragraph copy unless the user explicitly asks. A metric-panel edit is separate from the overview paragraph.

Metric layout: use large bold figures; four stats in a 2×2 grid, three with two above and one centered below, two side by side, and one centered. Center the stats vertically and use the available overview-side area.

**Why:** The user explicitly asked to preserve paragraph copy unless requested and repeated the symmetry requirement for three-stat blocks.

**How to apply:** During portfolio metric updates, change the stats data independently, preserve non-requested overview copy, and check desktop and mobile symmetry.
